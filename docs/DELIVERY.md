## 建议体验顺序

先看视频，再打开在线产品。点击「体验演示」即可检查提醒、去重、数据异常、恢复和冷却；这些是明确标注的构造数据，使用相同的规则引擎和持久化流程。

体验真实链路时，点击「新建任务」，输入「贵州茅台跌幅达到3%，并进入热榜前10时提醒我，冷却24小时」。核对草稿，预检真实数据，再确认启用。真实任务在网页关闭后继续由服务器调度，提醒保存在应用内。评审后可以暂停自己创建的真实任务。

市场休市或数据跨日时，真实任务可能显示未到检查时间或数据不可用；页面会给出原因。异常没有被替换成构造行情。演示场景可以在休市期间完整体验主链路。

## 视频段落

视频是线上产品的实际操作录屏，剪除了等待间隔，并补录证据和最终提醒追溯画面；没有用动画模拟应用运行。无配音，使用中文字幕说明。

| 时间 | 内容 |
|---|---|
| 00:00–00:33 | 自然语言输入、实际模型草稿、条件与频率修改 |
| 00:33–00:54 | 真实预检，以及历史真实证据的来源、时间与单位 |
| 00:54–01:14 | 确认启用、立即检查和暂停 |
| 01:14–01:48 | 构造场景中的首次提醒、持续满足去重、过期 / 冲突 / 失败与恢复 |
| 01:48–02:02 | 新一轮冷却与到期提醒；推进的是隔离演示时钟 |
| 02:02–02:36 | 新版本、保留旧规则与冷却、暂停恢复、提醒回到旧版检查 |

`verification/video-edit-manifest.json` 记录原录屏片段范围与字幕。视频中的金融数值均对应展示的历史检查或构造场景，不代表当前行情。真实后台调度另有独立证据。

## 实际验证与范围

最终 **46 / 46 项自动测试、27 / 27 项线上 API 检查通过**，TypeScript 与生产构建通过。真实 Cron 在客户端进程退出后完成检查，执行记录保存在 `verification/cron-proof.json`。浏览器核验了桌面和 390px 手机布局、真实创建流程和演示流程。

`verification/integration-first-retrace.json` 保留一次 26 / 27 的失败结果：模型给盘中计划返回了不参与执行的 `at=null`。修正只规范化该模式无关字段，没有猜测有效时间、频率或阈值。随后新增回归测试，并再次完成真实 API 验证；最终结果见 `integration-report.json`。

当前覆盖 A 股单证券价格、涨跌幅、热榜与日历组合。公告事件、多证券联动、邮件 / 推送、登录同步与长期稳定性验证尚未完成；完整边界见 README。产品提供条件监控与研究信息，不提供交易或仓位建议。
