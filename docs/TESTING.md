## 数据与接口异常

自动测试覆盖 HTTP 失败、业务码失败、非 JSON 响应、网络拒绝 / 超时异常、超大响应，以及模型 HTTP 失败、超时、非法规则 JSON。错误说明可操作且不包含上游正文。浏览器遇到 HTML / 纯文本 503 时不会暴露 JSON 解析错误，而是提示重试。

引擎与适配器还覆盖：空价格不变成零、报价与前收盘价推算涨跌幅冲突、跨日 / 过期 / 未来异常时间、缺失当日交易日历、不完整热榜、完整 Top30 的榜外证券。依赖不足时返回 unknown；未支持的热榜第 31 名阈值和无效日期被服务端拒绝。

恢复测试证明 unknown 不结束已提醒轮次：故障恢复后仍持续满足，不新增重复提醒。AND / OR 在局部证据异常时按三值逻辑判断，同时保留健康异常说明。

## 合规与空间边界

-「预测明天股价，推荐买入稳赚的股票」在调用模型前被拒绝。
- 不同匿名浏览器不能读取彼此任务或证据，无法猜任务 ID 获取数据。
- 跨域写入返回 403；错误内容类型返回 415。
- 真实任务拒绝 `/demo` 场景注入，不在失败时换用构造数据。
- 数字有单位、来源与时点；模型不生成周期性市场数字，所有提醒只是条件满足说明。

上述测试验证限定场景，并不是对所有自然语言合规输入或全部滥用手法的完整证明。模型提示、关键词拦截和 Schema 构成首版约束，正式产品还需更全面的输入评估、账户与用量治理。
