# AI 使用与验证记录

## 开发过程

用户提供题目截图和原附件，选择第一题，要求严格按题目完成可运行作品、版本管理和全部交付物。用户授权 Codex 辅助产品设计、全栈实现、金融接口选择、测试、部署与材料整理；方案、界面、服务和测试代码主要由 Codex 生成并执行验证。本文明确披露 AI 参与，不声称这些工作完全由候选人独立手写。

用户确认运行时使用 DeepSeek Flash 的文字能力，并指出不宜使用其多模态。开发中读过题目全文、接口文档和实际响应，再把范围限定为单证券价格、热榜、日历及组合；未使用模型猜测行情。用户反馈初版界面“AI 味重”后，使用 frontend-design 与 UI UX Pro Max 重新组织任务表和详情，去掉装饰性标语与光效，复核移动布局和实际操作。

| 阶段 | 交给 AI 的问题 | 产物与检查 |
|---|---|---|
| 题目与计划 | 比较三题，并在第一题要求内选择可完成的主链路 | `PLAN.md`；逐项对应要求，平台 24 小时倒计时优先于附件的 48 小时文字 |
| 实现 | 如何把自然语言转换成可修改规则，并保持长期执行状态 | 统一 Schema、确定性引擎、Worker / D1 / Cron；规则、并发、异常和真实 API 验证 |
| 界面迭代 | 投资工作台如何减少模板化视觉、便于反复检查 | 当前中文任务表、详情栏和移动布局；截图与浏览器操作核验 |
| 交付 | 如何说明实际完成范围和验证证据 | README、设计与测试说明、运行报告、实际操作录屏 |

## 运行时模型

后端调用 DeepSeek 原生 `/chat/completions`，模型参数 `deepseek-flash`，JSON 输出、低温度、关闭 thinking。系统提示限定可用字段、单位、阈值、未支持事项与澄清要求；提示文本位于 `src/server/providers.ts`。模型的证券名称 / 代码查询由真实检索确认，草稿经过 Schema 校验，最后由用户确认启用。

`deepseek-flash`是API调用名称。依据 [2026-09-10官方发布说明](https://api-docs.deepseek.com/news/news260910/)，截至2026-10-01它对应的实际模型版本为 **DeepSeek V4.1 Flash**。这是服务商维护的别名，不保证未来始终指向同一版本；审计与验证报告保留API实际返回的 `model` 字段，不将其误写成固定版本凭据。本项目仅使用文字能力。

### 思考与生成参数评估

2026-10-01 13:00（上海时间）核对实际请求后，确认原配置已显式关闭思考，1800 tokens是生成上限，并非独立思考预算。依据 [DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/) 和 [Chat Completions 参数说明](https://api-docs.deepseek.com/api/create-chat-completion/)，最终保留关闭思考，并显式设置 `reasoning_effort: none`；不依赖服务默认的思考模式和强度。

| 参数 | 当前值 | 依据 |
|---|---|---|
| `thinking.type` / `reasoning_effort` | `disabled` / `none` | 交互式、限定字段的规则提取；模糊需求应澄清，不能靠更多推理猜阈值 |
| `max_tokens` | 1800 | 最多6个条件；本次最终配置样本的生成用量为69–145 tokens，保留输出余量；达到上限即拒绝该草稿 |
| `temperature` | 0.1 | 非思考模式使用低随机性，优先稳定的结构化提取 |
| `response_format` | `json_object` | 系统提示同时要求JSON；返回后仍做服务端Schema及证券检索校验 |
| 请求超时 | 35000毫秒 | 为网络波动留余量；失败时提示重试或手动配置，已启用监控继续运行 |

使用实际生产适配器和相同系统提示，对6个预先规定的输入进行真实API对比：跌幅与热榜AND、价格与涨幅OR、日期与每日时刻、模糊阈值、未支持公告、6条件组合。关闭思考与低强度思考均为6/6通过，耗时中位数分别为995.5毫秒和3953.5毫秒，平均completion用量分别为98和721.2 tokens。低强度对照使用 `thinking: enabled`、`reasoning_effort: low`、`max_tokens: 4096`；未设置在思考模式下不生效的temperature。

因此本次样本没有提供启用思考的收益证据。13:03用最终配置再次真实调用，同样6/6通过，中位数1045毫秒。报告分别为提交包 `verification/model-config-comparison.json` 和 `verification/model-config-selected.json`，包含输入、草稿、逐项断言、耗时、用量、请求ID及提示哈希；不保存或展示思考正文。最终配置报告还记录适配器源码SHA-256。

这是每种配置、每个输入一次调用的小样本检查，耗时含本地代理；不是统计性的模型排名，也不保证所有自然语言输入都能正确解析。结构校验中的证券身份使用预设的已知测试证券，不冒充真实消歧；线上端到端验证另检查真实证券检索。模型只在用户创建草稿时调用，不用于持续研究或多工具规划，因此不把high/max或大额思考额度用于该链路。

模型不执行监控、不自动选择买卖、不提供仓位或涨跌预测。启用后只调用金融接口与确定性规则引擎；模型不可用时可手动配置，已有任务不受模型故障影响。

线上真实调用已核验：组合条件得到 `≤ -3%` 与 `≤ 10 名`；模糊“大跌”返回澄清；回购公告返回不支持。审计保存模型名、输入 SHA-256 哈希、验证状态、服务返回 token 用量和时间，当前空间可查询 `/api/ai-audit`。提交包 `verification/ai-verification.json` 是实际 D1 记录摘录，不包含密钥或完整对话。失败在返回前发生时尚未建立完整失败审计，这属于未做事项。

## 实际发现、修正与复核

| 问题 | 修正 | 复核 |
|---|---|---|
| 初期考虑了“前50”热榜示例，但接口仅返回前30 | 收紧规则阈值，榜外只说明未进入前30；不编造名次 | Schema、完整 / 不完整榜单、真实预检 |
| 交易日历只覆盖至当日 | 未来日期仅给计划；盘中 / 收盘执行时确认当天交易日 | 日历适配器、上海时区和调度测试 |
| 客户端模型别名不一定可作为服务端 API 模型名 | 核对实际模型接口，使用 `deepseek-flash` | 真实调用与审计记录 |
| 用 `snapshot` 子串判断接口类别，误把行情标成热榜 | 使用明确路径判断证据类型 | 浏览器行情 / 热榜标签与原字段 |
| 开发服务重启时返回非JSON503，出现底层解析报错 | 客户端识别网关 / 网络错误，提示重试 | 3 项客户端错误处理测试 |
| 初读持续状态与取得租约之间可能有其他检查提交 | 取得租约后重读最新状态，提交使用版本与令牌校验 | D1 并发集成测试与去重断言 |
| 跳过检查可能清除既有失败状态 | 跳过保持健康状态与失败计数，不假装恢复 | 跳过路径检查与后续恢复流程 |
| 运行完成时间曾复用开始时间，早于实际采集 | 实际运行以采集后时钟记录完成；演示保留明确场景时钟 | 集成断言与重新执行真实 Cron，23:35:14.889 完成晚于所有采集 |
| 用户认为视觉模板化 | 改为任务表与检查详情，中文实用文案、克制色彩和清晰层级 | 新版构建、真实创建流程和390px无横向溢出 |
| 真实模型返回盘中计划 `at=null`，使无关字段阻止了正确条件 | 只规范化该模式不参与执行的字段；不改阈值，不猜 daily 时刻或 intraday 频率 | 保留失败报告，新增四项回归测试并再次验证真实模型 |
| 提醒只能进入历史列表，定位具体检查不够直接 | 按提醒运行 ID 自动展开，增加受空间权限保护的单条记录查询 | 实际浏览器展示旧版 v1 与完整检查 ID，集成验证查询及跨空间404 |
| 独立产品裁判发现演示任务不可清理、总额度提示暂停却无法释放 | 删除确认与同空间 API；级联清理并阻止在途执行复活；满额提示区分总数与运行数 | 六项新增实际 API 检查，本地及线上各33项通过；浏览器删除与取消 |
| 独立裁判以延迟真实响应复现 B 高亮却显示 A 详情 | 详情请求取消保护、刷新序列与当前选择校验 | 同一延迟场景在部署后再次核验，见 AUDIT.md |
| 筛选隐藏新任务、旧规则结果可能被误读、固定演示值语义模糊 | 创建回到全部 / 最新；新版本未检查提示；固定构造值说明 | 独立产品裁判的新鲜页面截图和流程复核 |
| 测试工具扫描到提交包源码的测试副本 | 明确限定真实测试目录 | 46项、3个源测试文件；未把92项重复执行当新增覆盖 |
| 用户视角 Agent 复现编辑后关闭或切换直接丢失草稿 | 有改动才确认离开，默认保留，明确放弃后继续原操作 | 独立本地及主 Agent 线上确认取消/Escape保留、无改动不弹框 |
| 改规则后旧预检晚返回，附在新规则下方 | 清除旧结果并核对请求序列与规则内容，提示重新预检 | 原问题含真实金融预检；本地与线上合成延迟响应回归 |
| 关闭新建后迟到解析重新打开草稿 | 取消、替换或输入修改后忽略旧解析结果 | 明确标记合成模型响应，本地与线上取消场景通过 |
| 手机保存失败原因在页首屏幕之外 | 编辑器内显示原因并移入焦点，保留草稿 | 390×844真实API拒绝热榜31，修正后保存v2通过 |
| 核对思考预算时发现未专门识别输出达到长度上限 | 显式关闭思考并设置none；`finish_reason=length`拒绝，即使内容仍能解析为JSON | 真实两模式各6项对比、最终配置6项复核及一项截断边界回归；自动测试增至47项 |
